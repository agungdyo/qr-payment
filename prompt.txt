## Key facts to reason about (do not skip)
- In React Router v7, for `/admin/workspaces/new` the STATIC segment `new`
  outranks the dynamic `:workspaceCode`, so the URL matches the
  `workspaces/new` route, which declares NO `:workspaceCode` param.
- Consequence: inside WorkspaceFormPage, `useParams()` returns `{}`, so
  `workspaceCode` is `undefined` for this URL (it is NOT the string `"new"`).
- Trace what happens with `workspaceCode === undefined`:
  * how is `isNew` computed?
  * how is the initial `loading` state computed?
  * in the `useEffect`, does the early `return` happen BEFORE the fetch's
    `.finally()` that would call `setLoading(false)`?
  * Therefore: does `loading` ever become false? That is why the spinner never
    goes away and the form never renders.
